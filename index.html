📝별지 제1호 — 감리자 지정 신청서
프로젝트 정보 탭의 데이터가 자동 반영됩니다. 탭 전환 시 자동 갱신됩니다.
📊별지 제2호 — 자기평가서
I. 총괄표: 감리자(회사)+감리원 합산 100점 자기평가서 자동 생성
II. 감리원 경력환산서: 감리원별 경력 세부 내역
📑별지 제3호 — 입찰서 + 부표 배치계획표
입찰서와 감리원 배치계획표가 A4 양식으로 자동 생성됩니다.
